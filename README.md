# FundCare v5.3 基金组合智能分析工具

FundCare 是一个基于 Next.js 的基金组合智能分析项目。用户输入基金代码与持仓金额后，系统会识别基金名称，并在分析阶段完成主题分类、最近交易日涨跌估算、沪深300基准对比、新闻情绪判断和 AI 组合报告。

## 运行方式

```bash
npm install
npm run dev
```

打开：

```txt
http://localhost:3000
```

## DeepSeek API 接入

在项目根目录新建 `.env.local`：

```bash
DEEPSEEK_API_KEY=自己的 DeepSeek API Key
```

保存后重启：

```bash
npm run dev
```

不要把 API Key 写进前端代码，也不要使用 `NEXT_PUBLIC_` 前缀。

## v5.3 新增内容

1. 01 新增截图识别持仓（Beta）：上传截图后在浏览器端 OCR，生成待确认列表后再导入。
2. 01 本地保存提示移动到模块底部。
3. 02 删除每行数据来源列，改为表格底部统一说明。
4. 02 基金明细表列头支持升序、降序、恢复默认，移动端增加排序下拉。
5. 02 估算涨跌幅展开后增加沪深300基准对比，不再接入偏股型基金指数。
6. 03 组合结构分析改为左侧主题配置结构、右侧主题盈亏贡献柱状图。
7. 03 饼图、图例与柱状图支持联动高亮；右侧柱状图下方显示主题基金盈亏详情。
8. 04 清洗新闻标题脏字符，删除重复市场情绪卡片，保留右上角情绪 Badge。
9. 05 报告操作按钮横向并列：复制、TXT、Markdown、打印/保存 PDF。
10. 全站标题改为“基金组合智能分析工具”。

## 注意

本工具仅用于基金组合信息整理和风险提示，不构成投资建议。基金估值、新闻抓取、沪深300基准和 AI 生成内容均可能存在延迟或误差，最终以基金公司及正式披露渠道为准。
