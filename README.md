# FundCare：基金组合智能分析工具

## 1. Intro 项目简介

FundCare 是一个面向个人基金持仓场景的基金组合智能分析工具。用户输入基金代码和持仓金额后，系统可以自动识别基金名称，并进一步完成主题分类、当日涨跌估算、新闻情绪判断和 AI 组合分析报告生成。

本项目不是收益预测工具，也不提供明确买卖指令，而是用于帮助用户整理基金组合信息、理解主题分布、观察组合波动来源和识别结构性风险。

根据课堂展示后的修改意见，最终版在 01 持仓录入模块中增加了 **AI 图片识别辅助导入 Beta**：用户可以上传或拖入支付宝/基金平台持仓截图，系统先进行 OCR 文字识别，再调用 AI 将 OCR 文本整理为基金代码、基金名称和持仓金额等结构化字段，生成待确认列表，用户确认后再导入持仓表。

## 2. Frame 项目框架

项目采用 Next.js + TypeScript 开发，包含前端页面和后端 API 接口。

- 前端框架：Next.js
- 编程语言：TypeScript
- AI 接口：DeepSeek API
- 图片识别：Tesseract.js OCR + DeepSeek 文本结构化识别
- 可视化模块：主题占比饼图、主题盈亏贡献图、指标卡片
- 代码托管：GitHub
- 云端部署：Netlify

## 3. 功能模块

### 01 持仓录入与基金识别

用户可以输入基金代码和持仓金额，系统自动识别基金名称。支持导入演示组合、修改演示组合、AI 图片识别辅助导入和批量文本导入。

### 02 持仓明细与组合概览

展示组合规模、估算盈亏、估算涨跌幅和集中度风险。支持金额隐藏功能，保护用户隐私。基金明细表支持排序，移动端也做了适配。

### 03 组合结构分析

左侧展示主题配置结构，右侧展示主题盈亏贡献。点击饼图、图例或柱状图后，系统会联动高亮对应主题，并展示该主题下基金盈亏明细。

### 04 市场新闻情绪

系统抓取财经新闻标题，并按照积极、消极、中性进行初步分类。新闻列表默认折叠展示，用户可以展开查看全部新闻，也可以查看情绪判断依据或原文链接。

### 05 AI 组合分析报告

系统调用 DeepSeek API，根据基金持仓、主题分布、估算盈亏、新闻情绪和基准信息生成结构化 AI 报告。报告分为组合概览、主要风险、市场情绪、主题结构、优化方向和注意事项六部分。

## 4. Agent 设计说明

本项目可以理解为一个基金组合智能分析 Agent。它的流程为：

1. 用户输入或导入基金持仓；
2. 系统识别基金名称；
3. 系统进行主题分类；
4. 系统估算组合当日涨跌和主题盈亏贡献；
5. 系统抓取财经新闻并判断新闻情绪；
6. 系统调用 DeepSeek API 生成结构化组合分析报告。

新增的 AI 图片识别辅助导入模块可以理解为 Agent 的输入增强能力，用于降低手动录入成本。识别结果保留人工确认环节，避免截图识别误差直接写入持仓。

## 6. 本地运行方式

```bash
npm install
npm run dev
```

浏览器打开：

```text
http://localhost:3000
```

## 7. DeepSeek API 配置

如果需要启用 DeepSeek AI 报告和 AI 图片识别结构化功能，需要在项目根目录新建 `.env.local` 文件，并填写：

```env
DEEPSEEK_API_KEY=自己的 DeepSeek API Key
```

然后重新运行：

```bash
npm run dev
```

注意：`.env.local` 不应上传到 GitHub，也不应放入提交压缩包。
